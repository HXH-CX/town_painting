# 镇在画中 · 产品需求文档(v0.1)

> 状态:已确认(2026-11-23)· 上游:[RESEARCH.md](./RESEARCH.md)

## 1. 概述

- 产品名:镇在画中
- 一句话:三座风格化小镇,一键切换三种画风,点街推镜进入探索。
- 目标用户:碎片时间"云逛街"的大众访客;评审。
- 成功标准:
  - 访客 30 秒内完成"进镇 → 切画风 → 进街"核心循环;
  - 公网移动端首屏 < 3s,操作无可感知卡顿;
  - 任一画面可深链接分享。

## 2. 信息架构

```
首页(三镇卡片墙)
├─ 枕河镇(江南) ── 全景 ── 石桥码头 / 茶馆老巷
├─ 汐见町(日式) ── 全景 ── 坂道商店街 / 海堤电车路
└─ 钟崖堡(欧式) ── 全景 ── 钟楼石阶广场 / 河岸旧城巷
```

全局:画风切换器、声音开关、分享、页脚声明。

## 3. 页面需求

### S1 首页

- 大标题「镇在画中」+ 副题「三座小镇,三种笔触」。
- 三张镇卡片(横排/竖排自适应):封面为该镇写实全景;镇名 + 一句话简介;悬停轻微视差。
- 点击卡片 → 1s 推镜(卡片图放大铺满视口 → 交叉溶解到全景)+ 镇档案浮现(约 2s 后淡出)。

### S2 小镇全景页

- 全景图铺满,Ken Burns 慢漂移。
- 街道热点 ×2:柔和光晕,悬停浮出街道名;点击推镜进入街道。
- 镇档案:镇名 + 一句话 + 1 行诗意文案,入镇时浮现一次。
- 面包屑:← 镇在画中(回首页)。
- 顶部工具栏:画风切换器(写实 / 水彩 / 像素)、声音开关、分享。

### S3 街道页

- 街道主图 + Ken Burns。
- 故事热点 ×2~3/街(全站 15 条):点击弹出卡片(标题 + 1–2 句诗意旁白)。
- 同镇街道互跳(「去另一条街」胶囊)。
- 返回全景;面包屑「枕河镇 / 石桥码头」。
- 同 S2 工具栏。

## 4. 交互细则

| 交互 | 行为 | 时长 |
|---|---|---|
| 画风切换 | 交叉溶解 + 1.00→1.02 轻推;连点以最后一次为准 | 350–450ms |
| 推镜进街 | 以热点为原点放大至 2.2x,再溶解到街道图 | 约 700ms |
| 返回 | 反向缩回 | 约 700ms |
| 热点悬停 | 浮出标签 + 光晕;触控设备直接点击 | 150ms |
| 故事卡 | 桌面右侧浮卡 / 移动端底部抽屉;点空白、X、ESC 关闭 | 250ms |
| 空闲氛围 | 灯笼光晕/炊烟粒子;reduced-motion 时停用 | 持续 |
| 声音 | 默认关;开启 400ms 淡入;记住偏好;切镇换曲目 | 400ms |
| 分享 | 复制深链接(含镇/街/画风),toast 提示 | — |
| 浏览器返回 | 历史栈正常;首屏返回不白屏 | — |
| 加载 | 当前画面先进 LQIP 模糊版,大图淡入 | 300ms |

## 5. 状态与异常

| 场景 | 处理 |
|---|---|
| 深链接非法参数 | 回落首页 |
| 图片加载失败 | 显示 LQIP + 自动重试 1 次,仍失败给出提示 |
| 弱设备/低端机 | 关视差与粒子,仅保留溶解 |
| 慢网 | 先低清后高清,不阻塞交互 |
| 浏览器不支持 AVIF/WebP | 降级 JPG(960w) |
| 自动播放策略 | 默认静音,仅用户手势后播放 |

## 6. 内容需求

### 6.1 三镇档案(镇名已定;文案为终稿语气示例)

| 镇 | 一句话 | 档案文案 |
|---|---|---|
| 枕河镇 | 河道穿过镇子的年月 | 「先有河,后有桥,再后来,才有了在桥上停留的人。」 |
| 汐见町 | 坡尽头的海 | 「坡道一阶阶走完,海就在眼前铺开。」 |
| 钟崖堡 | 建在石头上的城 | 「钟声比人先醒,石阶比路更老。」 |

### 6.2 故事卡 15 条(诗意旁白;以下为语气示例)

- 石桥码头:「桥拱把月色分成两半——一半给河,一半给赶路的人。」
- 茶馆老巷:「茶凉了三次,话题才从今年的雨,讲到三十年前。」
- 坂道商店街:「傍晚六点,风铃和收摊的木板声一起响。」
- 海堤电车路:「电车驶过时,海面刚好装下最后一格夕阳。」
- 钟楼石阶:「钟声落下之前,鸽子先绕着石阶飞了一圈。」

其余 10 条按同语气补全,进入实现阶段随数据文件定稿。

## 7. 路由与深链接

- `#/` 首页;`#/zhenhe` 镇全景;`#/zhenhe/bridge` 街道
- 画风参数 `?style=cinematic|watercolor|pixel`,默认 cinematic
- 优先级:URL 参数 > 本地记忆 > 默认
- 声音偏好仅本地记忆,不进 URL

## 8. 非功能需求

- 性能:首屏资源 < 2MB;单图 ≤ 400KB;LCP < 2.5s(4G);转场 60fps。
- 适配:≥360px 宽;桌面 16:9 铺满;移动端横竖屏;热点触达区 ≥ 44px。
- 无障碍:键盘可达热点与关闭;focus-visible;aria-label;尊重 prefers-reduced-motion。
- 兼容:Chrome/Edge/Safari/Firefox 最近两个大版本;iOS 15+。
- SEO/分享:title/description/og:image 静态配置;深链接可直接打开。

## 9. 验收标准

1. 三镇 × 三画面 × 三画风共 27 组画面全部可达且无 404。
2. 画风切换 ≤ 450ms 完成,连续切换不闪烁。
3. 全景↔街道转场在中端手机达到 60fps(允许瞬时 50)。
4. 首屏(4G)可交互 < 3s,首屏资源 < 2MB。
5. 深链接打开直达对应画面与画风;分享复制可用。
6. 声音默认关闭;开启后生效,切页保持。
7. 360px 宽移动端全流程可用,热点可点。
8. 弱设备降级生效,无报错。
9. 键盘可关闭故事卡;reduced-motion 下无大幅动效。
10. 页脚含 AI 生成与音效来源声明。

## 10. MVP 边界与后续

- 本版做:上述全部 + 3 镇档案 + 15 条故事卡 + 环境音 + 深链接。
- 后续:江南第三街、更多画风、昼夜滤镜、分享海报、访问统计。
