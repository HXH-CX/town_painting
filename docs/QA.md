## 已知环境限制(非代码问题)

- 内嵌浏览器面板 hidden 时:lazy 图片挂起、真实按键默认动作不投递、截图不可用 → 已改用即时加载/合成事件/evaluate 验证。
- Vite HMR 的 `?t=` 模块缓存会使动态 import 读到旧实例 → 音频验证改用开发态 `window.__ambience` 挂点。
