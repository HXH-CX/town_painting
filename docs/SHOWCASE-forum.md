## 二、你的作品是什么

**一句话**:给碎片时间想"云逛街"的人做的网页虚拟城镇——打开链接走进一座细腻的小镇,一键切换三种画风,点一条街道镜头就推近带你进去。

三座虚构小镇:枕河镇(江南水乡,石桥、乌篷船、茶馆灯笼)、汐见町(日式海边,坂道、贩卖机、海堤电车)、钟崖堡(欧式山城,钟楼、石阶广场、河岸晾衣绳)。每座镇 1 张全景 + 2 条街,共 9 个场景;每个场景提供**写实电影感 / 水彩手绘 / 复古像素**三种笔触,27 组画面由 9 张母版参考图派生,构图逐元素对齐——切换时是"同一座镇换了笔触",不是套滤镜。

交互:点镇卡片 FLIP 推镜入镇;点街道热点以热点为原点放大推镜入街;点街上光斑读一句诗意旁白(全站 15 条故事卡);右上角切换画风、开关环境音、复制"某镇某街某画风"的深链接分享。环境音为 WebAudio 程序化合成:枕河镇水声、汐见町风铃、钟崖堡教堂钟,默认静音。

## 三、为什么做

通勤和午休的碎片时间里,人们缺少"低门槛、纯欣赏、可分享"的氛围型内容:图片和视频只能看,不能"逛"。而 AI 图像生成让"同一构图、多种画风"第一次能以低成本成立——这是交互与美术结合的新体验形态,也是我想验证的产品假设。

比赛语境下我给自己定了三条底线:**性能红线**——首屏 <2MB、转场 60fps、弱设备自动降级,公网作品不能卡;**版权干净**——27 组画面全部 AI 原创生成并登记母版/派生关系,环境音程序化合成,不抓任何网络素材,字体用系统字体栈;**体验诚实**——验收不过不报完成,环境限制与代码缺陷分开定位,不谎称已验收。

## 四、怎么用(5 步)

1. **打开作品链接** https://painted-towns-f75gxhr5rba.qoder.zone ,无需注册登录,手机/电脑浏览器均可(手机竖屏会自动改全图布局,热点保证可点)
2. **选一座镇**:首页三张镇卡片,点一张,镜头推镜入镇,镇档案浮现一句开场旁白
3. **换笔触**:右上角「写实 / 水彩 / 像素」三档,同机位交叉溶解瞬间变身;选择会被记住并写进链接
4. **走进街道**:点全景上的街道光斑,镜头以光斑为原点推近入街;点街上光斑读故事卡(ESC 或点空白关闭);「去另一条街」胶囊可互跳
5. **带走画面**:点分享按钮复制当前深链接(含镇/街/画风),发给朋友打开即是同一画面;喜欢安静就保持默认静音,想听水声风铃钟声再开声音开关

## 附:技术栈与红线

- 前端 React 19 + TypeScript + Vite;自研 hash 路由(≈60 行);动效仅 CSS transform/opacity/filter + Web Animations API,零动画库、零 WebGL
- 图片管线:sharp 裁 AI 角标 → 480/960/1600 三档 AVIF/WebP + 960 JPG 兜底 + 32px LQIP;单图 AVIF 105–235KB(红线 300KB);首屏 332KB、CLS 0、JS+CSS 80.6KB gzip
- 环境音:WebAudio 程序化合成(噪声+滤波+振荡器泛音列),零录音素材;默认静音,首次用户手势后才创建 AudioContext
- 降级:`prefers-reduced-motion`、`saveData`、低端设备检测、`?lite=1` 四路;竖屏 contain 全图布局保证热点可点
- 版权与隐私:27 组画面全部 AI 原创(母版+派生登记于 assets-src),无外部图片/字体/录音素材;不收集任何用户数据,偏好仅存本地 localStorage
- 素材与验收记录:docs/RESEARCH.md、PRD.md、TECH_DESIGN.md、QA.md、SUBMISSION.md;热点核对图 docs/assets/hotspots-check.jpg
